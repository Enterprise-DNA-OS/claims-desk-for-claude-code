# Make the claims desk yours

Read the current schema, CLI, import guide and service rules. Ask for the desired field, vocabulary or record check. Back up a business workspace first. Write a new numbered migration, never edit an applied migration. Update the CLI, import mapping, views, documents and tests that use the field.
